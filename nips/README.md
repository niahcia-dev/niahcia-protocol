# NIAHCIA Improvement Proposals (NIPs)

NIPs are the mechanism for proposing significant changes to NIAHCIA protocol behavior, standards, interfaces, or governance processes.

## Categories

- **Core** — consensus, chain, execution, networking
- **AI** — jobs, workers, verification, runtimes
- **Agent** — agent identity, versions, tools, memory
- **Service** — storage and service-node standards
- **Interface** — RPC, wallet, frontend, SDK standards
- **Meta** — governance and NIP process

## Lifecycle

```text
Draft -> Review -> Accepted -> Implemented
                  \-> Rejected
Draft/Review -> Withdrawn
```

Acceptance of a NIP does not necessarily activate it on a production network. Activation rules are defined separately where required.
